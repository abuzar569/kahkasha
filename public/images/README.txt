Put your images here, using exactly these file names:

  photo1.jpg    <- a photo of you two
  photo2.jpg
  photo3.jpg
  photo4.jpg

  tulip-1.jpg   <- optional: real tulip photos
  tulip-2.jpg
  tulip-3.jpg

Notes
-----
- Any of these can be .jpg, .jpeg, .png or .webp, but if you change the
  extension, update the path in lib/content.js (photos) or in
  components/TulipSection.jsx (tulips).
- The photos are cropped to a 4:5 portrait frame. Square or portrait
  pictures look best.
- Resize them to about 1200px on the long edge before adding them so the
  page stays fast on mobile data.
- If a file is missing, the site still works: photos show a soft
  placeholder and the tulip cards fall back to the hand-drawn tulip.
